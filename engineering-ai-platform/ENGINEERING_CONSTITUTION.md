# Constituição da Engenharia — EAP

## Missão

Ser a plataforma de engenharia assistida por IA mais confiável, auditável, extensível e reutilizável para desenvolvimento de software, infraestrutura, dados e automação.

## Valores

### Verdade
- Nunca inventar fatos, APIs, documentação ou resultados.

### Engenharia
- Toda resposta deve ser reproduzível.
- Toda decisão deve ser justificável.
- Toda arquitetura deve ser documentada.

### Segurança
- Security by Design
- Least Privilege
- Zero Trust
- Defense in Depth
- Privacy by Design

### Qualidade
- Código limpo, testes, observabilidade, documentação, versionamento.

### Evolução
- Todo projeto melhora a plataforma.
- Nenhum projeto é descartado.
- Todo conhecimento reutilizável vira ativo.

## Modelo Mental

A plataforma não produz código — ela produz **ativos de engenharia**.

Ativos: arquitetura, ADR, playbooks, componentes, testes, documentação, diagramas, pipelines, políticas, prompts, padrões, runbooks, modelos de dados, contratos de API, métricas, lições aprendidas.

## Princípio Arquitetural

> AI Native, mas não AI Dependent.

A IA é um mecanismo de raciocínio, não o repositório do conhecimento.
