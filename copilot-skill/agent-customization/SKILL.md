# Agent-Customization Skill: Create Repository Skill

## Purpose
Provide a repeatable workflow for extracting a multi-step process from a conversation and turning it into a repository-scoped `SKILL.md` that documents the process, decision points, quality checks, and example prompts.

## When to use
- You and the agent followed a repeatable methodology (debugging, PR review, feature rollout) and want to codify it for future use.
- You need a workspace-scoped or personal quick-reference that the assistant can follow automatically.

## Outcome
A repository file describing:
- The step-by-step process
- Decision points and branching logic
- Quality criteria / completion checks
- Example prompts and usage

## Extract Steps (How the agent should work)
1. Review conversation history and any linked files.
2. Identify the step-by-step procedure being followed (1..N steps).
3. Note decision points and branches (if X then A else B).
4. List quality criteria for each step (checks, metrics, tests).
5. Draft a concise SKILL.md following this template.
6. Save SKILL.md under `copilot-skill/agent-customization/SKILL.md` in the repo.
7. Highlight ambiguous areas and ask clarifying questions.

## Decision Points
- Is the skill workspace-scoped or personal? (workspace by default)
- Is the workflow quick (3–5 steps) or full (detailed, with checks)?
- Are there external tools or commands required to verify steps?

## Quality Criteria / Completion Checks
- Each step has a clear action and expected observable outcome.
- Decision branches are explicit and testable.
- Example prompts demonstrate how to invoke the skill.
- File saved in repo and linked back to the user for review.

## Template (Use to fill in SKILL.md content)
- **Name:** Short name for the skill
- **Scope:** workspace | personal
- **Goal:** One-line purpose
- **Preconditions:** Files, tools, or context required
- **Steps:** Ordered list with expected outcomes
- **Decision points:** Conditions and branches
- **Checks:** How to know the step is complete
- **Examples:** 3 example prompts to run the skill
- **Open questions:** Ambiguous items that need user input

## Example Prompts
- "Create a SKILL.md for the debugging workflow we used in the last conversation."
- "Turn our PR review checklist into a repository skill with checks and example prompts."
- "Draft a workspace-scoped SKILL.md that automates the release checklist."

2. Which conversation or PR should I extract the workflow from? Provide links or identifiers.
3. Which validations should be included (unit tests, lint, manual review)?
